# eliterasi-sd1
karya literasi sekolah
ersedia dashboard karya dengan contoh puisi, surat, cerpen, esai, resensi film/buku/musik, dan kisah inspiratif. Siswa dapat mencari dan memfilter karya, membaca isi lengkap, serta mengirim karya melalui formulir. Guru dapat meninjau kiriman, lalu menyetujui atau menolaknya dari Ruang guru.

Untuk mencoba panel guru, gunakan kode demo GURU-JENAKA. Catatan: ini prototipe frontend; data tersimpan hanya di browser yang digunakan
